🌟 Project Overview

CinemaCache lets users browse movies, view details, and stay up-to-date with trending films. Built with performance and user experience in mind, it provides a responsive interface and fast navigation.

🛠 Technologies Used

Frontend: React.js

Styling: Tailwind CSS

Deployment: Vercel

🚀 Features

Browse popular and trending movies

Search for movies by title

View movie details, including synopsis, rating, and release date

Responsive design for desktop and mobile

Fast and smooth UI interactions

💻 Installation

Clone the repository:

git clone https://github.com/yourusername/CinemaCache.git
cd CinemaCache


Install dependencies:

npm install


Start the development server:

npm run dev


Open http://localhost:3000
 in your browser.

📦 Deployment

The app is deployed on Vercel:

https://cinema-cache.vercel.app/
